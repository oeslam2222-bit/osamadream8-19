# دليل إدارة المستخدمين — منظومة طنطاوي دريم (Saja / Dream)

> للإدارة والمطورين. يشرح إدارة الحسابات وكلمات المرور والقطاعات بعد ترحيل المصادقة المركزية.

## 1) المبدأ الأساسي
- **كلمات المرور تُدار في Supabase Auth فقط** — التطبيق لا يقرأها ولا يخزّنها ولا يستطيع تغييرها.
- كل مستخدم له:
  - حساب في **Supabase Auth** (الإيميل + كلمة المرور).
  - صف في **public.users** (الاسم، الدور، الفرع، القطاع، المشرف...).
  - الربط بينهم عبر `auth_user_id` + `auth_email`.

## 2) تغيير / إعادة تعيين كلمة مرور
1. افتح **Supabase Dashboard → Authentication → Users**.
2. ابحث بالإيميل (مثال: `osama@dream.com` أو `rep27@dream.com`).
3. الثلاث نقاط ⋮ → **Reset password** (أو Edit user → New password).
4. أبلغ الموظف بالكلمة الجديدة.
5. (اختياري) فعّل **Send recovery email** لو الإيميل مضبوط.

> ⚠️ لا توجد شاشة لتغيير كلمة المرور داخل التطبيق — هذا بصميم مقصود للأمان.

## 3) إضافة مستخدم جديد
1. أنشئ الحساب في **Supabase Auth** بإيميل الموظف وكلمة مرور مؤقتة.
2. أضف صفاً في **public.users** بنفس الإيميل والاسم والدور والفرع والقطاع.
3. عند أول دخول، التطبيق يربط `auth_user_id` تلقائياً (`linkAuthUserToProfile`).

## 4) تعيين قطاع المستخدم (مهم)
- عمود `users.sector` يحدد ما يراه المستخدم: `home` (منزلي) أو `electrical` (كهرباء).
- **الإدارة/المطور** يستطيعون التبديل بين القطاعين بالزرار 🏠/⚡ في أعلى الصفحات.
- **المندوب/المشرف/مدير الفرع** مقفولون على قطاع حسابهم — لا يرون القطاع الآخر.
- لتغيير قطاع مستخدم:
  ```sql
  update public.users set sector = 'electrical' where id = '<user_id>';
  ```
- القطاعات موزّعة حالياً: 52 منزلي / 38 كهرباء / 24 حسابات إدارية بلا قطاع.

## 5) إيقاف مستخدم
```sql
update public.users set is_active = false where id = '<user_id>';
```
(أو من لوحة Supabase: حذف/تعطيل حساب Auth).

## 6) ملفات مرجعية في المشروع
- `auth-temp-passwords.csv` — كلمات المرور المؤقتة للمستخدمين الأصليين (77).
- `electrical-reps-accounts.csv` — حسابات مناديب الكهربا (37).
- `LICENSE` + `THIRD_PARTY_NOTICES.md` — الترخيص.

## 7) أمان
- ⚠️ أي مفتاح خدمة (service_role key) ظهر في محادثة أو ملف عام يجب إعادة توليده (Regenerate) في Supabase قبل الإطلاق.
- لا تضع مفاتيح الخدمة في الكود أو الفرونت إند أبداً.
